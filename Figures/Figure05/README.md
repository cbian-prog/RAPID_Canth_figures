# Figure 5

Annual AMOC strength at 26.5°N (maximum over depth of the overturning streamfunction), 1850–2100, ensemble mean ± 1 standard deviation.

## Data

- `data/RAPID_Figure05_data.csv`: `scenario`, `year`, `mean`, `std` (Sv)

Run `python plot.py` from this folder. It reads only `data/` and writes `RAPID_Figure05.png`. The data files are written by `analysis/export_figure_data.py` from the output of `analysis/compute.py`.
