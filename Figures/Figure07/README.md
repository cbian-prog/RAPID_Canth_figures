# Figure 7

Annual area-weighted mean C_anth concentration on the 26.5°N section, 1850–2100, ensemble mean ± 1 standard deviation.

## Data

- `data/RAPID_Figure07_data.csv`: `scenario`, `year`, `mean`, `std` (mol m⁻³)

Run `python plot.py` from this folder. It reads only `data/` and writes `RAPID_Figure07.png`. The data files are written by `analysis/export_figure_data.py` from the output of `analysis/compute.py`.
